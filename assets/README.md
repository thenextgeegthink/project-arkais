# Project Arkais — Visual Assets

This directory is reserved for custom brand assets and visual designs created by the author/maintainer.

## Hero Banner Specification
- **File Name**: `banner.png` (or `banner.svg` / `banner.webp`)
- **Target Dimensions**: ~1280px × 400px (or 16:9 / 3:1 aspect ratio)
- **Placement**: Once added, uncomment the banner tag in `README.md`:
  ```html
  <p align="center">
    <img src="assets/banner.png" alt="Project Arkais Banner" width="100%">
  </p>
  ```
